# Security Policy

## Supported versions

Until WorldDevKit reaches 1.0, security fixes are provided for the latest published minor release.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for `KobotAI/world-protocol`:

<https://github.com/KobotAI/world-protocol/security/advisories/new>

Do not disclose the issue publicly until a fix is available. Include affected versions, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge a report within five business days and coordinate remediation and disclosure.

## Scope

Reports about applications integrating WorldDevKit should be sent to those applications' operators. This repository covers vulnerabilities in the protocol schemas, published packages, release pipeline, and examples.
